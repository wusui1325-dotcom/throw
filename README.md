# THROW — 無盡物理投石守塔

> 免費開源、打開即玩的物理破壞無盡投石守塔網頁遊戲。  
> **線上遊玩**：[https://throw.wusper.com](https://throw.wusper.com)

## 核心機制與特色

- **無血條、純視覺物理破壞**：
  - **敵艦與海盜船員**：不顯示任何生命值與血條，改以船體裂縫、吃水下沉、船身傾斜、冒煙起火與船員狀態直觀呈現。
  - **石塊動態碰撞機制**：投石命中敵船會依動能與入射角觸發三種動態結果——高速撞擊**碎裂成飛濺碎石**、斜角著陸**於甲板滾動並壓扁海盜船員**，或重擊**直接砸穿船底斷裂沉船**。
  - **可破壞高塔結構**：高塔中彈會於精準撞擊高度鑿出真實凹陷缺口、產生裂縫並彈飛建築碎塊，受損嚴重時塔身傾斜，直到支撐不住發生物理崩塌。
- **天氣與海浪風向物理**：動態切換晴夜、海霧、強側風與暴風雨，風向會真實影響拋物線彈道（瞄準虛線同步反映風偏）與海浪起伏。
- **黑白 / 透明平面流線體 UI + 手機豎屏適配**：全按鈕與道具配備獨立 SVG 向量圖示；手機豎屏自動切換滿版垂直視口與底部拇指操作欄。
- **無盡強度與清場加速 ×3**：隨時間提升強度並解鎖 7 種海盜敵軍，清場時觸發 3.5 秒敵軍來襲速度 ×3。
- **連擊倍率、實體金幣與塔樓掛件**：連續命中累積最高 ×3.0 金幣倍率，商店（開啟暫停時間）提供 9 階高塔加固、5 種投擲物、5 種技能與 3 種塔樓掛件（自動連弩、防空攔截網、金幣磁石）。
- **全球無盡排行榜**：透過 Cloudflare Workers + KV（`worker/leaderboard.js`）即時同步全球存活時間與擊敗紀錄。
