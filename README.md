# THROW — 無盡投石守塔

> 免費開源、打開即玩的物理拋物線投石守塔網頁遊戲。  
> **線上遊玩**：[https://throw.wusper.com](https://throw.wusper.com)

## 遊戲特色

- **黑白 / 透明平面流線體 UI**：極簡高對比玻璃擬態介面，所有按鈕、投擲物、技能與商店項目均配備獨立向量 SVG 圖示。
- **物理拋物線投石操作**：支援「拖曳蓄力瞄準」與「點擊快速拋射」，可攔截敵方空中砲彈、擊中海盜觸發暴擊並擊沉敵艦。
- **無盡強度進程**：隨時間提升強度等級，逐步解鎖海盜輕舟、弓手帆船、加農砲艦、裝甲衝撞艦、海盜投石艦、海盜飛艇與無畏黑帆旗艦。
- **清場加速 ×3**：清空場上所有敵人時，觸發 3.5 秒敵軍來襲速度 ×3 狂潮。
- **時間暫停商店系統**：開啟商店時自動暫停戰場時間，包含：
  - **9 階塔的加固**：木塔 → 石塔 → 木板混合石塔 → 鐵塔 → 框架鐵塔 → 水泥塔 → 鐵架水泥塔 → 鋼塔 → 鋼筋水泥塔。
  - **5 種投擲物（左上角切換 / 快捷鍵 `1`–`5`）**：石頭（初始無限，0.5 秒充能 1 顆，上限 1 顆）、三連石、炸彈、刺球、火球（皆可強化升級）。
  - **5 種戰術技能（右上角拖拽或點擊施放）**：修復塔、區域箭雨、5 秒盾、區域火球、水雷。

## 本地運行

純前端靜態專案，零建置依賴，直接以任意靜態伺服器開啟即可：

```bash
npx serve .
```
